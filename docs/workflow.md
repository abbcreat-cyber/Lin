# 山河制图台 · 地图库

运行 `py -3 launch.py` 或双击 `启动地图库.cmd`，打开本地地图库。默认端口 8797。Codex 工作时按 AGENTS.md 在侧面打开页面。

1 号：六国争中原（默认原始三阶段模板）。
2 号：四陆环斗（四大陆与中央斗兽场）。

每张地图保留真实制作时间及依据、原始地形、彩色分区、动态地块和接入包。卡片可进入工坊查看三个阶段、复制替换指令，或点击“发给别人”生成地图项目压缩包。卡片编号固定，排序或搜索不改变编号。

`catalog.json` 是权威索引；`library.py list` 列出编号，`library.py verify` 验证资源，`library.py export 2` 为 2 号生成包，省略编号则处理全部地图。导出需要 Pillow，网页使用 launch.py 提供的本地服务；分享与导入需要该服务的项目接口。

库中项目状态与游戏当前使用的地图相互独立；查看或下载不会切换游戏。按编号正式接入见 INTEGRATION.md。

交付时复制整个目录，两张地图已包含在其中；无需另外到旧工作区寻找图片。三阶段确认和纠错规则见 STAGE-REVIEW.md。

素材工坊 ui/ 保存当前五种礼物、礼物框/地图框的尺寸位置、默认款及测试款。2 号图已装配朱雀赤金测试款，正式游戏未更改。可在工坊切换款式，描述风格后复制生图要求给 AI。

## 两个页面

地图库负责找图和入库档案；工坊负责选定地图的三阶段、推进取景、框与礼物、给ai提示词。统一入口 workshop/?map=N，旧链接会自动跳转。右侧工具切换不会重置当前推进；静态阶段会暂停；返回图库后保留选图、阶段、样式、辅助线和未发送的意见草稿（仅本机浏览器）。离开页面或换地图会重开预览对局，不持久保存战场进度。

小兵行为已固化为共享引擎，第三阶段接入数据后可自动逐块推进；每图只有3个演示起点。点击“快速验收这张地图”或运行 `node accept-map.mjs N`，直接用相同行为引擎快速模拟并输出结果。详见 workshop/ENGINE.md。框与礼物可在加宽侧栏直接点选、滚动、收藏；“全部”保留搜索与筛选。

## 发给别人 / 导入项目

在地图库或工坊点击“发给别人”，生成 packages/project-NNN.zip。项目包包含三阶段原画、动态地块、制作记录、框和礼物素材；不安装对方提供的代码，也不重复携带共用引擎。框选择会读取当前浏览器的试装状态，图片内容按 SHA-256 只存一份。

接收方把 ZIP 拖入地图库，或点击“选择项目压缩包”。现有公共素材按内容复用，缺少的补齐；不同素材同名时保留两份并重新映射。编号冲突分配新的本地编号，来源编号保留。同一版本重复导入会打开已有地图。导入的新地图应重新运行快速验收。

launch.py 仅监听本机，替代旧的纯静态 http.server；已有正确版本服务时复用。项目文件仍在当前工作流目录，不写正式游戏目录。首页“新建地图”直接进入空白工坊；填写名称与要求后保存独立编号、brief.json 和三阶段档案，只开放第一阶段。创建完成后在“给ai提示词”中复制制作要求。

## 四陆环斗 · 抖音预览

当前独立预览位于 douyin-preview/map-002，由 build-douyin-preview.mjs 直接打包本工作流的推进、战斗和染色模块。当前版本使用测试号，显示 ui.audience 观众范围，保留朱雀框、礼物区和框外压暗；用户已目视确认通过。构建与打开此工程不修改旧 Cocos 工程。地图二进制使用 .bin 扩展名，以便开发者工具纳入资源。后续需要同步新状态时执行 node build-douyin-preview.mjs 2，再在这个独立工程编译。
