# 框与礼物的可复用工作流

入口已融合到 workshop/?map=2&panel=appearance。旧 ui/index.html 自动跳转；standalone.html 仅为内部兼容样本。manifest.json 保存当前游戏测量的默认槽位、5 个礼物、参与说明、地图框和礼物框版本。默认素材是青龙地图框与古金礼物框；朱雀赤金是本次测试款，只配置在 2 号地图 presentation.json，未替换正式游戏默认值。

## 换风格流程

1. 读取 manifest 的 source/audience、mapOpening、mapFrame、giftFrame。坐标是完整 9:16 来源画布上的逻辑尺寸；观众画面是中间 80%，不能把 393 宽误当成完整来源宽再重复裁剪。
2. 用 imagegen 参考相应原框生成新外观，保存新版本；不把礼物图标、文字烘焙到框内。礼物框保留暗底，地图开口和框外保留真实透明。
3. 读取生成资产的真实尺寸/透明通道，标定骨架边轨 railRect，不能把避开爪子/羽毛的最大空白矩形当成边轨。renderer.mjs 绘制全部九片，包括中央原始 alpha 和伸入地图的装饰，不能跳过或清空中央。地图内容自身不随换框拉伸。外框尺寸与目标开口必须都保持，不能为迁就新图挤压地图或移动礼物区。
4. 在素材工坊可比较当前默认与新款，再写指定地图的 presentation.json。在该地图 index.html 加载 ui/overlay.mjs（当前 2 号已接入；其他地图复用时动态读取本地图编号，禁止沿用示例编号）。
5. 验证默认/新款的外框矩形、地图开口和礼物图标坐标一致，地图中央自然透明且伸入的装饰完整，屏幕外裁剪与原布局一致，所有图标/指令可见，尺寸改变后仍按比例，地图点击不被装饰拦截。

地图框素材原图 1024×1536，原始开口 [98,166,828,1324]。现有外框 388.823×839.488；内框314.4×723.621，顶端5%。框装饰顶端可能超出屏幕，原布局就是如此。

礼物框 393×130，中心距底部52，可见117；五个29×29图标、现有文案与说明条分别绘制。参与说明沿用源矩形 [0,80,2170,96]，渲染时沿用游戏的黑底透明化阈值30/70。没有改变原图文件。

素材全部随工作流存储。正式游戏应用新皮肤时仍需更新相应UI素材映射/开口参数并真实预览验收；仅修改地图数据包不足以修改游戏HUD。

## 多素材选择

工坊加宽侧栏直接展示地图框和礼物框卡片，点击立即试装；每块独立滚动，星标收藏保存在本机。原“更换”按钮改为“全部”。统一选择器提供分类、名称/编号搜索、默认/测试筛选、选中标识、独立滚动和每页24款的加载更多；素材数量增长不会无限拉长侧栏。选中后点试用，更新当前地图的本机预览偏好。

当前边轨：青龙 [98,166,828,1324]；朱雀 [98,166,828,1296]。朱雀旧的 [140,180,744,1250] 只是避开羽毛的空白框，已弃用。不能再以中央整块零透明度作为合格条件；需分别验证透明中心、内伸装饰与四边贴合。
