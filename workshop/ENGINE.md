# 固化的小兵行为与快速验收流水线

任何地图完成第三阶段后都使用同一个 `TroopPipeline`，不为每张图新写一套排队脚本。

## 数据契约

地图只提供：territories.json（width/height/territories）、同尺寸 little-endian territories.u16（0 是不可玩区域，包括海域与框外装饰）、原画/材质/边线，以及 demo-pairs.json。演示配置恰好 3 项，每项 source、target 为接壤地块，label 与位置不同。当前 2 号选择中央、东北桥、左下大陆；1 号选择中部、上方、下方。

`workshop/pipeline.mjs` 是唯一推进状态机，`troop-rules.mjs` 是持续兵群/寻路层。游戏现有 PersistentTroops 的规则依据与来源哈希记录在 troop-rule-provenance.json。只将几何查询适配到像素归属；包含演示单位的独立血量与战损，不包含正式游戏英雄伤害、礼物结算或兵力经济。

## 行为

初始部队在己方领地内随机巡游；点击开始推进后，80% 主力从当前坐标集结，20% 留守。必须有真实可达前线接触才计入 20 秒推进。占领后自动从己方地盘选择下一块相邻地，连续推进；只能沿真实己方陆地行走，不能借道或跨海。无连接的离岛不伪造占领。窄处使用与实际兵身绘制一致的碰撞尺度；旗帜也检查归属范围。

暂停冻结模拟，重置恢复原画/归属/起点；主力回防停止原进攻并沿己方领地返回；后方遇袭时守军就近迎敌，主力保持原命令，直到用户下令回防。更换起点重置当前演示。队伍身份与位置跨命令、跨占领保持连续。

## 快速验收

工坊按钮“快速验收这张地图”在 Worker 中直接运行同一个 TroopPipeline，通过固定时间步快速模拟，而不是把另外一套假动画当测试。每处检查巡游、下令不瞬移、80/20、无接触不推进、兵身/留守限界、暂停、自动连续占领至少两块（每块接触累计20秒）、水域隔离与重置。只用 3 个不同区域，不扩张演示菜单。

也可在工作流根目录执行 `node accept-map.mjs 2`。无 npm 依赖。输出该地图 quick-acceptance.json，包含 pass/fail、三处结果、引擎版本和数据哈希。失败须修正数据或共享引擎并复验，不能写成已通过；用户目视效果确认仍单独保留。

接入新图步骤：登记地图和三阶段文件 → 导出区域数据 → 配置3处起点 → 复用工坊入口 → 快速验收 → 给用户看自动推进效果。换图不复制修改行为代码。

## 地图框是硬边界

构造 TroopPipeline 时必须传入 ui/manifest.json 的 source/mapOpening 布局；导出数据也可使用 atlas.playableArea.layout。缺少边界直接报错，禁止默认全图可玩。共用 playable-area.mjs 按居中 cover 换算实际像素内缘，把框外 ID 和归属清零，重算框内面积、中心及接壤。编号保持稳定，完全在框外的旧编号保留空占位（active=false、area=0、neighbors=[]），不得生成单位或参与目标选择。

跨框地块仅框内像素可玩；寻路不能借道框外连接其他部分。关闭辅助线、隐藏装配或切换相同槽位的皮肤均不改变边界。框外只画原始 reference；动态染色、旧边线清理、地块诊断与点击不得越界。快速验收与导出均调用同一个边界模块，不能单独裁剪显示冒充玩法限制。

## 接触对战与回防

引擎默认 combatEnabled=true，prepare 建立本方和目标守军。attack(source,target) 为另一个势力下令，不覆盖本方指令；raidHome() 选择本方驻地相邻敌区模拟后方遇袭；recall(owner) 停止该势力的原进攻，主力沿己方可达领地返回。所有指令都保持位置和血量连续。阵亡部队从队列移除，同一局不自动复活。

combat.mjs 只在实际距离和陆地视线满足时结算双方攻击，同一时间步先汇总再同时扣血。参数在 COMBAT_RULES；这是地图验收用的小兵数值，不是正式游戏礼物兵力账本。活兵保护周围像素，接触前线会受守军阻挡；无守军处继续按真实邻接逐步吞噬。占地本身不扣对方血量。框外与海域不能用于接战、移动或占领。前线目标只追踪尚未占领像素，避免在已经变色的位置停滞。

runtime.mjs 展示挥击、受击、血条、阵亡效果及双方战损。无人防守模式 combatEnabled=false 仅用于基础吞噬验收。快速验收每个起点先检查基础推进，再用 combat-check.mjs 检查双方伤亡、守军抵抗、主力指令保持、回防不瞬移、原进攻停止、暂停和重置；三处演示共用同一引擎。
