已确认阶段 1 地形 terrain-v1.png；已确认阶段 2 彩色设计 colored-v2.png。colored-v1.png 是被否决的失败记录，不参与运行。

当前阶段 3 已实现，等待用户验收。访问 http://localhost:8797/projects/four-continents-arena/ 。选择“动态领地”，点击出兵块及相邻目标，或从三个位置中选择后播放。接触边界后累计 20 秒推进；暂停冻结士兵与染色；完成后部队在已占领区域继续活动；恢复原貌重置归属与图像。前三阶段都能对照，切换静态图时会暂停推进。

## 数据形成与纠错

extract.py 读取本项目 base.png（等同 terrain-v1.png）、reference.png（等同 colored-v2.png）。用原始地形辅助排除蓝绿色领地误判水域；颜色聚类提取稳定色块种子，分水岭扩展区域。灰白岸线/建筑描边不作为独立色块种子。每个 ID 拆为单一四连通区，隔海同色岛屿不会共用一个可穿越区域。

输出 251 个连通区域（含沿海小岛），并不宣称这是阶段 2 人工指定的确切地块数。保留原画、材质、边界与像素归属分层；初始合成与彩色设计逐像素一致。debug-regions.png 仅用于检查数据，不替代游戏原图。

## 验证证据

- extraction.json：原图哈希、维度和提取覆盖记录。未分配像素为 0 是相对提取陆地掩膜而言，不代表有人工逐像素标注的绝对海陆真值。
- topology-verification.json：全部 ID 连通、内部锚点有效、邻接双向；中央/四桥/四大陆的独立位置探针及主要海峡水域探针。
- runtime-verification.json：旧版九处路径记录仅作历史参考；中央场地、东北桥、左下大陆三次真实时间推进均 20 秒完成，水域未染色，士兵未越界，暂停和占领后活动正常，重置差异为 0。

复现提取：在项目目录运行 `py -3 extract.py`（需要 numpy、Pillow、scipy、scikit-image、scikit-learn）。提取改动后必须重新生成演示对并重做拓扑/运行验收，不得沿用旧报告。
